# Feedback Lab glossary

Feedback Lab helps instructors inspect AI feedback on introductory Python assignments and helps researchers evaluate that feedback against evidence.

## Language

**Function assignment**  
A Python exercise whose test cases call a named function and check the value it returns.

**Script assignment**  
A Python exercise whose test cases supply text as standard input and check the text printed to standard output.

**Rubric criterion**  
An expectation used to assess a submission. Its stable identifier lets a feedback comment cite the exact criterion in the rubric version used.

**Submission version**  
A particular snapshot of a synthetic Python submission, including the source that was tested and reviewed.

**Targeted correction**  
A deliberate change made to address a known error in a synthetic submission.

**Submission pair**  
An original submission version and a corrected submission version connected by a targeted correction.

**AI draft**  
The original feedback generated by the model for a submission. A reviewer can make decisions about its comments while the original remains available to the study.

**Pre-review feedback**  
The feedback a condition presents after its automatic processing and before instructor review. The research comparison scores this version.

**Reference validation**  
A check that a cited rubric criterion, source range, or test result exists for the relevant version, together with checks for contradictions the platform can verify.

**Substantive support**  
The assessment that the available evidence justifies a feedback claim.

**Unsupported comment**  
Feedback that contains at least one checkable claim that conflicts with the evidence or cannot be established from it.

**LLM judge**  
A scoring model that assesses whether each feedback claim is supported by the rubric, source code, and recorded test results.

**Scoring key**  
The expected errors and acceptable evidence established independently of AI feedback for an evaluation case.
